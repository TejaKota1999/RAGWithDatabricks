# Free-tier checklist

Phase 0 deliverable. Fill in before running any cloud action.

- [ ] Databricks Free Edition workspace available (cloud: Azure or AWS, confirm)
- [ ] Notebook / Spark / Delta / Unity Catalog features checked against current limitations docs
- [ ] Managed AI Search, Model Serving, Apps: pricing and availability checked (not created)
- [ ] Sample dataset is synthetic or public (5-20 documents)
- [ ] Local components selected: sentence-transformers, FAISS or Chroma, Ollama, Streamlit, pytest

Official docs to verify:
- https://www.databricks.com/learn/free-edition
- https://docs.databricks.com/aws/en/getting-started/free-edition-limitations
